Support

CloseProof for Jira is maintained by an independent developer.

Get help

Open an issue at github.com/neimasilk/closeproof/issues. Please include:

  • what you were doing (dashboard, issue panel, Rovo agent or MCP tool);
  • the message CloseProof showed, if any;
  • the control ID involved (C1 to C7), if any.

Do not post balances, statements or other confidential financial data in a public issue. Describe the problem with made-up numbers instead.

We aim to reply within two business days (UTC+7).

Common questions

The Close Controller agent is missing

The agent needs Rovo on your site. Everything else in CloseProof works without Rovo.

"You need EDIT_ISSUES permission"

Editing reconciliations, signing off, loading the demo and issuing certificates require the Edit issues permission in that Jira project. Reading the close requires Browse projects.

C5 says an evidence file changed, but nobody touched it

C5 compares the file's current SHA-256 with the fingerprint stored when it was attached. Any change, including re-saving the same statement or uploading a new version with the same name, changes the fingerprint. Attach the new file as evidence, remove the old one, and sign off again.

Can I remove the demo?

Yes. Clicking Load demo close again rebuilds the demo period, and the demo issues are normal Jira issues you can delete.

Security

To report a security problem privately, use GitHub's private vulnerability reporting for the repository instead of a public issue.
